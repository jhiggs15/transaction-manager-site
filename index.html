Transaction Manager

Transaction Manager is a personal budgeting app for one household. It runs on a private home server and is not offered to the public.

What it does

It brings the household's bank and card transactions into one place, sorts them into categories, and gives each one a clear name so the monthly budget is easy to read.

Card charges from services like Uber and Lyft often show up with vague names. With the owner's permission, the app reads the matching receipt emails in their Gmail inbox and uses the details to label the charge, for example where a ride started and ended.

Google sign-in

The app asks for read-only Gmail access. It can read messages but cannot send, delete or change anything. See the privacy policy for how that data is used.
