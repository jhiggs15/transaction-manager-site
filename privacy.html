Privacy policy

Transaction Manager is a private budgeting app used only by the members of one household. This policy covers the data it accesses through Google.

What data the app accesses

With each user's consent, the app uses the Gmail read-only permission (gmail.readonly) to read receipt emails, such as ride receipts from Uber and Lyft, in that user's own inbox.

How the data is used

Receipt details (amount, date, merchant and trip details) are matched to the user's own card transactions so each transaction gets an accurate name and category. The app does not send, delete or change any email.

Where the data is stored

Data is stored on a private server in the household's home. It is not stored with any other company and is not published.

Sharing

Google user data is never sold, never used for advertising, and never used to train AI models. It is not shared with anyone outside the household except where needed to run the features described above.

Transaction Manager's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

A user can revoke the app's access at any time at myaccount.google.com/connections. On request, the household owner deletes that user's stored receipt data.

Contact

Questions can be raised as an issue on this site's GitHub repository.

Effective November 17, 2026.
